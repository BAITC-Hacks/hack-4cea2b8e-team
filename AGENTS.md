# Инструкции для AI-агентов (Codex)

Общий файл для всех троих. Читается агентом перед работой.

---

## Задача

**Кейс:** «Граф денег» — восстановление финансовой структуры организованной
группы по транзакционной сети. HackAlem AI, 23.09.2026.

**Пользователь:** AML-аналитик банка второго уровня. Ему известен только нижний
уровень цепочки — 81 клиент, получавший деньги. Кто собирает эти деньги, через
кого их прогоняют и кто ими распоряжается, он восстанавливает вручную неделями.

**Что делаем:** инструмент, который строит граф переводов, присваивает каждому
узлу роль с объяснимым обоснованием, разбивает сеть на кластеры и выдаёт
аналитику ранжированный топ-лист «кого проверять первым».

**Основной сценарий:** выгрузка .parquet → пайплайн → три CSV + экран со схемой
сети, где видно направление потоков, роли и поиск по gid.

## Пять обязательных требований

Без них решение не считается выполненным.

1. **Воспроизводимый пайплайн.** Одна команда от сырых .parquet до трёх выгрузок,
   без ручных шагов, меньше 5 минут.
2. **Роль и скор у каждого узла.** Все ~2 248 узлов: роль из словаря,
   `role_score`, непустой `evidence`.
3. **Критерии ролей объяснимы.** Жюри назовёт 3 произвольных gid — команда за
   минуту объясняет роль, опираясь на свои метрики. Пороги — в одном месте.
4. **Кластеризация.** Размер, число seed, оборот и гипотеза по каждому кластеру.
5. **Топ-лист ≥ 20 узлов + визуализация** со схемой сети, направлением потоков,
   подсветкой ролей и поиском по gid.

## Ловушки данных — учитывать обязательно

Объявлены в ТЗ, их учёт оценивается отдельно.

- **Обрыв на 4-м колене.** 444 узла с `depth=4` имеют нулевые исходящие. Это
  граница выгрузки, а не «деньги осели». Правило `out_degree == 0 → terminal`
  даст 444 ложных срабатывания. В коде эти узлы помечены `truncated`.
- **Только исходящие переводы.** Полный баланс узла недостоверен.
- **У seed занижены входящие** — граф собран от них. Отношение «отдал/получил»
  для seed не применимо, флаг `ratio_reliable`.
- **Порог 5 000 ₸** — дробление ниже порога невидимо.
- **31 seed из 81 без исходящих переводов.**
- **16 слабосвязных компонент**, 352 узла вне крупнейшей.

## Запреты из ТЗ

- **Не хардкодить результат** — никаких зашитых списков gid «под правильный ответ».
- **Не сдавать чёрный ящик** — роль без объяснимого правила не засчитывается.
- **Не обогащать внешними источниками.** Пол, возраст, доход, организация — этих
  полей нет в данных, любые такие атрибуты считаются выдумкой.
- **Не требовать GPU, облако или платные сервисы** для воспроизведения.
- **Осторожные формулировки.** «Признаки консолидации», а не «организатор».
  Выводы — гипотезы для проверки, не утверждения о виновности.

## Структура

```
pipeline/graph.py   — загрузка parquet, метрики узлов, компоненты, кластеры
pipeline/roles.py   — THRESHOLDS и правила ролей, priority_score
pipeline/run.py     — единая точка запуска, пишет три CSV
scripts/explore.py  — распределения для подбора порогов
app/                — FastAPI: отдаёт данные графа на экран
web/                — экран просмотра сети
tests/              — проверки по must-have
```

## Границы зон

Никто не редактирует файлы вне своей строки.

| Зона | Файлы | Кто |
|---|---|---|
| Пайплайн и API | `pipeline/*`, `app/*` | Никон |
| Визуализация сети | `web/*` | Костя |
| Пороги, выгрузки, тесты, README | `pipeline/roles.py` (THRESHOLDS), `tests/*`, `README.md`, `docs/*` | Аргын |

## Правила работы

1. Не трогай файлы вне своей зоны. Нужна правка в чужой — скажи, не делай сам.
2. Все пороги — в `THRESHOLDS` в `pipeline/roles.py`. Нигде больше магических чисел.
3. Каждое правило роли возвращает `evidence` с конкретными числами из данных,
   до 200 символов, понятное аналитику без ML-образования.
4. Пайплайн детерминирован: `seed=42` в кластеризации, никакой случайности.
5. Вызовы модели — только через `app/llm.py`. Второй клиент не создавать.
6. Секреты только через `app/config.py`. Ключей в коде нет.
7. Не добавляй зависимостей без необходимости. Добавил — зафиксируй версию и
   впиши в `docs/THIRD_PARTY.md`.
8. Не переписывай то, что работает. Рефакторинг ради красоты запрещён.

## Проверка

```bash
pytest -q
python -m pipeline.run --data data/ --out out/
```

Тесты зелёные, пайплайн отрабатывает, три CSV на месте. Сломал — чини сразу.

## Стиль

- Русские комментарии и тексты, английские имена переменных.
- Типы в сигнатурах — да, полное покрытие — нет.
- Коммиты: `тип: что сделано`, типы `feat`, `fix`, `style`, `test`, `docs`,
  `data`, `chore`. Историю читает технический эксперт.
- **Коммитит человек, не агент.** Не запускай `git commit` сам: участник должен
  видеть, что уходит в историю, и коммит должен быть от его имени.
- Никогда не добавляй ключи, `.env` и содержимое `data/` в коммит.
