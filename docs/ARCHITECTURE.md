# Архитектура

> Заполните в течение первого часа. Этот файл — материал и для эксперта,
> и для слайда на Demo Day, и одновременно засчитывается как подтверждённый
> промежуточный результат по п. 5.4.8.

## Поток данных

```
   пользователь
        │
        ▼
   web/index.html ──fetch──► FastAPI /api/*
                                  │
                   ┌──────────────┼──────────────┐
                   ▼              ▼              ▼
              app/llm.py     app/db.py     <внешний сервис>
                   │              │
              OpenAI API      SQLite
```

## Компоненты

| Модуль | Ответственность | Почему так |
|---|---|---|
| `app/main.py` | HTTP-эндпоинты, отдача статики | Один процесс — нечего настраивать проверяющему |
| `app/llm.py` | Вызовы модели, демо-режим, лог | Смена провайдера = одна переменная окружения |
| `app/db.py` | Хранение и журнал | SQLite: ноль внешних зависимостей |
| `app/config.py` | Конфигурация | Всё через env, никаких секретов в коде |

## Принятые решения

| Решение | Альтернатива | Почему выбрали это |
|---|---|---|
| Фронтенд без сборки | React + Vite | Экономит ~40 минут и исключает «у эксперта не собралось» |
| SQLite | Postgres | Не нужен второй контейнер и миграции |
| Демо-режим на заглушках | Выдать эксперту свой ключ | Требование п. 5.6.6 + ключ не утечёт |
