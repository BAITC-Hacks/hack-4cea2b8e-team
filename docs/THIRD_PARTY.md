# Сторонние компоненты

Версии установки зафиксированы в `requirements.txt`. Перечень прямых зависимостей:

| Компонент | Версия | Лицензия | Использование |
|---|---|---|---|
| FastAPI | 0.115.6 | MIT | HTTP API и статика |
| Uvicorn | 0.34.0 | BSD-3-Clause | Локальный ASGI-сервер |
| Pydantic | 2.10.4 | MIT | Проверка HTTP-параметров |
| pandas | 2.2.3 | BSD-3-Clause | Таблицы, агрегации и CSV |
| NetworkX | 3.4.2 | BSD-3-Clause | Граф, компоненты, Louvain и циклы |
| PyArrow | 18.1.0 | Apache-2.0 | Чтение parquet |
| httpx | 0.28.1 | BSD-3-Clause | HTTP-клиент и TestClient |
| pytest | 8.3.4 | MIT | Тесты |
| openai | 1.59.6 | Apache-2.0 | Необязательный LLM-модуль стартового каркаса |
| python-dotenv | 1.0.1 | BSD-3-Clause | Поддержка конфигурации окружения |
| python-multipart | 0.0.20 | Apache-2.0 | Разбор multipart в стеке приложения |

NumPy используется в расчётах и устанавливается как зависимость pandas.
Транзитивные версии не зафиксированы полным lock-файлом; для строго одинаковой
изолированной установки следует сохранить подготовленный набор wheel-пакетов.
Лицензии Python-пакетов поставляются в их дистрибутивах.

## Библиотеки браузера

| Компонент | Версия | Лицензия | Локальный файл |
|---|---|---|---|
| Vue | 3.5.22 | MIT | `web/vendor/vue-3.5.22/vue.global.prod.js` |
| vis-network, standalone UMD | 9.1.9 | MIT или Apache-2.0 | `web/vendor/vis-network-9.1.9/vis-network.min.js` |

Оригинальные готовые сборки получены из официального npm registry:

- https://registry.npmjs.org/vue/-/vue-3.5.22.tgz
- https://registry.npmjs.org/vis-network/-/vis-network-9.1.9.tgz

Файлы не модифицированы. Тексты лицензий лежат рядом со сборками;
оригинальные уведомления внутри standalone-сборки сохранены. Имена исходных
файлов архива и SHA-256 перечислены в `web/vendor/manifest.json`.
Обновление выполняется вручную с проверкой версии, лицензии и контрольной суммы.
Никаких загрузок npm/CDN при работе `/graph.html` нет.

Иконки ролей — символы Unicode системного шрифта внутри собственного SVG;
кружки и счётчики формируются кодом интерфейса. Внешних наборов изображений,
платных шрифтов или скопированных ресурсов Linkurious нет; его интерфейс
использовался пользователем как визуальный ориентир.

## Данные

Предоставленная организаторами выгрузка кейса «Граф денег»: три parquet,
июль 2026, 2 248 обезличенных клиентов. По условиям ТЗ — исключительно
для использования в рамках хакатона. Исходные данные не включаются в Git,
не отправляются внешним сервисам и не дополняются выдуманными атрибутами.

## Модели и заготовки

Основной пайплайн и графовый интерфейс не используют LLM. В стартовом
модуле есть необязательный OpenAI-совместимый клиент; модель и провайдер
задаются окружением. При `DEMO_MODE=1` внешних LLM-вызовов нет. Не заявляем
использование конкретной внешней модели в расчёте ролей.

В репозитории сохранён стартовый каркас FastAPI, SQLite и LLM-эндпоинтов.
Он отделён от добавленной аналитики в `pipeline/` и `app/graph_store.py`;
SQLite не является хранилищем транзакционного графа.

## AI-инструменты разработки

OpenAI Codex использовался для разработки и исправления пайплайна и API,
доработки интерфейса, проверки контрактов, запуска тестов, проверки действий
в браузере и подготовки документации. Результат расчёта формируется
детерминированным кодом, а не ответами модели на обезличенные данные.
